# 0074: The native app draws the scenes

Status: landed (2026-10-19, 32334e1)

Goal: the native binary shows a tech demo's scene through the engine's renderer, first person from the keyboard and the mouse, the plaques drawn by raylib, so the smelter's variants can be judged on the TV. The gamepad (0075) and the menu (0076) follow.

Verify:
- `./build.sh debug`, `release`, `check` and `test` pass; `./build.sh smoke` draws three frames of the models scene under Xvfb and exits 0 with no GL error line.

## Specification

- `src/app/demos.odin`: `Demo :: struct { name, description: string, scene: []byte, meshes: []runtime.Load_Directory_File }` and `DEMOS` with the four scene demos (`light`, `surface`, `cave`, `models`, not `hello`), each `scene` through `#load` of `data/demos/<name>/scene.sjson` and `meshes` through `#load_directory` of its `meshes/` directory where one exists (`models`), `nil` otherwise, the descriptions from `src/demos/<name>/description.txt` through `#load` as strings; the material library and textures every scene shares, `MATERIAL_LIBRARY :: #load("../../data/materials/library.sjson")` and `material_textures := #load_directory("../../data/materials/textures")` (the paths are relative to `src/app/`, as the demos' are to theirs).
- `src/app/main.odin`: after `rl.InitWindow`, `gl.load_up_to(3, 3, proc(pointer: rawptr, name: cstring) { (^rawptr)(pointer)^ = rl.glfwGetProcAddress(name) })` with `import gl "vendor:OpenGL"`, after which `print_gl_info` reads through `gl.GetString(gl.VENDOR)` and so on and the app's own `GL_*` constants and `Gl_Get_String` go; `--demo <name>` picks a demo (default `models`); a `Scene_View` initialised from it (`scene_view_init(&view, MATERIAL_LIBRARY, demo.scene, material_textures, demo.meshes, aspect)`) with the render size's aspect (`rl.GetRenderWidth` over `rl.GetRenderHeight`), a failed init printing the problem and exiting 1; the cursor disabled (`rl.DisableCursor`) unless `--windowed`; per frame: the input from `rl.IsKeyDown` (W, A, S, D, the arrows, E and Space up, Q, Shift and Control down, as the page's keys) and `rl.GetMouseDelta` times `APP_MOUSE_RADIANS_PER_PIXEL :: f32(0.003)`, `scene_view_step` with `rl.GetFrameTime`, then `rl.BeginDrawing`, `scene_view_draw` at the render size, the GL state given back to rlgl through its own calls (`rlgl.DisableDepthTest`, `rlgl.DisableBackfaceCulling`, `rlgl.DisableVertexArray`, `rlgl.DisableShader`, `rlgl.DisableFramebuffer`, `rlgl.DisableTexture`, `rlgl.EnableColorBlend` with `gl.BlendFunc(gl.SRC_ALPHA, gl.ONE_MINUS_SRC_ALPHA)`, since `rlgl.SetBlendMode` skips a mode its cache already holds and the renderer leaves blending off with the additive function, `rlgl.Viewport` at the render size, `import rlgl "shared:raylib/rlgl"`), one `rl.DrawText` per label at its `scene_view_label_screen` point when visible, centred by `rl.MeasureText`, 20 px white on a dark translucent `rl.DrawRectangle`, then the build stamp in a corner and `rl.EndDrawing`; Escape or `--frames` ends the loop; `scene_view_destroy` and `rl.CloseWindow` at the end. `free_all(context.temp_allocator)` closes every frame and follows the uploads, as the demos do: the texture row flips and the shader strings of the native GL api are temp copies.
- The GL error check in the smoke run: after the first frame `gl.GetError` is read once and a non zero value prints `gl error 0x...` on stderr and exits 1.
- `doc/build.md`: the app's flags; `doc/render.md`: one sentence that the native app runs the view through `vendor:OpenGL` loaded from raylib's GLFW and hands the state back to rlgl before raylib draws the text.
