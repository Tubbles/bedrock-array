## Specification (main agent, 2026-10-18)

Binding facts, read 2026-10-18: `forward.frag` shades with the uniforms `albedo`, `roughness`, `metallic` read inside `shade`; `forward.vert` passes `world_normal` and `world_position`; the draw loop of `webgl_renderer_draw` sets the three material uniforms per item; Mine oh Belowed's field shader (`~/dev/mine-oh-belowed/data/shaders/field.fs`, lines 59 to 72) projects along the three axes blended by `pow(abs(normal), 4)` normalised, reads the far scale at `position.zxy / 2.71828` with `blend.zxy`, and mixes near and far by 0.5. The triplanar normal is Ben Golus's whiteout blend (2017), with the projections' uv as `p.zy`, `p.xz`, `p.xy`.

- `src/engine/shaders/forward.frag`: a `struct Surface { vec3 albedo; float roughness; float metallic; }`; `shade` takes a `Surface` and reads its fields instead of the uniforms. New uniforms `int has_textures`, `sampler2D albedo_map`, `sampler2D normal_map`, `sampler2D surface_map`, `float texture_metres`. New procedures: `triplanar_blend(n)` (`pow(abs(n), vec3(4.0))` normalised to sum 1), `triplanar_colour(map, p, blend)` (the three projections, `texture(map, p.zy)`, `texture(map, p.xz)`, `texture(map, p.xy)`, weighted), `triplanar_two_scales(map, p, blend)` (`mix(triplanar_colour(map, p, blend), triplanar_colour(map, p.zxy / 2.71828, blend.zxy), 0.5)`), `triplanar_normal(map, p, n, blend)` (the whiteout blend: per projection `t = texture(map, uv).xyz * 2.0 - 1.0`, then `tx = vec3(tx.xy + n.zy, abs(tx.z) * n.x)`, `ty = vec3(ty.xy + n.xz, abs(ty.z) * n.y)`, `tz = vec3(tz.xy + n.xy, abs(tz.z) * n.z)`, `normalize(tx.zyx * blend.x + ty.xzy * blend.y + tz.xyz * blend.z)`, near scale only), and `surface_at(n) -> Surface` which returns the uniforms when `has_textures == 0` and otherwise, with `p = world_position / texture_metres` and the blend of the geometric normal, albedo `albedo * triplanar_two_scales(albedo_map, p, blend).rgb`, roughness `triplanar_two_scales(surface_map, p, blend).r`, metallic the uniform. `main` takes `n` from `triplanar_normal` when textured, else the geometric normal, and uses the `Surface` for the ambient term too.
- `src/engine/render_webgl.odin`: `Webgl_Uniforms` gains `has_textures, albedo_map, normal_map, surface_map, texture_metres: i32`, fetched in `webgl_renderer_init`; the three samplers are set once there to the units 0, 1 and 2 (`gl.Uniform1i`) and `texture_metres` to `WEBGL_TEXTURE_METRES :: f32(2)`. In the draw loop, a file private `webgl_bind_material_textures(renderer, uniforms, material: Material_Id)`: when `int(material) < len(renderer.texture_sets)` and the set is present (a material past the last set has no entry at all), bind its three textures to the units 0 to 2 (`gl.ActiveTexture(gl.TEXTURE0 + unit)`, `gl.BindTexture(gl.TEXTURE_2D, texture)`) and set `has_textures` to 1, else set it to 0.
- `doc/render.md`, The WebGL2 renderer, the forward pass sentence: the triplanar sampling in one or two sentences (the projections and the blend, the two scales with the ratio e, the whiteout normal, the near scale only for the normal, the preset tinting the albedo, `WEBGL_TEXTURE_METRES`).
