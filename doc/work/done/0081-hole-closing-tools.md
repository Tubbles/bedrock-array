# 0081: The hole closing tools

Status: landed (2026-10-19, 159fd06)

Goal: the low poly models can be closed before decimation by four techniques the demo then cycles through (0082 to 0084): Blender's fill holes and voxel remesh, MeshLab's screened Poisson reconstruction and alpha wrap (user, 2026-10-19: "which algos you think are worthwhile here"). The techniques are prebaked into blobs by the tools of this item; nothing runs in the demo.

Verify:
- `flatpak run org.blender.Blender -b --python "$PWD/tools/models/close.py" -- <in.glb> <out.glb> --technique fill` and `--technique voxel` print the triangle count before and after and write the GLB (the 12000 parts model, `work/models/smelter/model_7_faces12000.glb`, 10700 triangles: fill gives about 12500, voxel about 102000).
- `tools/models/reconstruct.py <in.glb> <out.ply> --technique poisson` and `--technique alphawrap` (run through `uv run --python 3.12 --with pymeshlab python -I ...`, the shebang line says so) print the face count and write the PLY (the same model: Poisson about 44600 faces, alpha wrap about 25900).
- `tools/models/decimate.py` accepts a `.ply` input as well as `.glb`.
- `tools/models/close_all.sh --dry-run` prints the commands for every variant; without it the script makes the 36 blobs under `data/demos/models/meshes/` (the main agent runs that, not the implementer).

## Specification

- `tools/models/close.py` (Blender, the shape of `decimate.py`: a docstring with the command line, `parse_arguments`, `reset_scene`, `mesh_parts`, `triangle_count`, `main`): `--technique fill|voxel`. `fill`: for each mesh part, edit mode, select all, `bpy.ops.mesh.fill_holes(sides=0)`, `bpy.ops.mesh.quads_convert_to_tris()`, object mode. `voxel`: all parts joined into one object (`bpy.ops.object.join` with every mesh selected and the first active), `data.remesh_voxel_size = 0.01` (the models are about 0.9 units high, so one percent), `data.remesh_voxel_adaptivity = 0`, `bpy.ops.object.voxel_remesh()`. Prints `closed <n> parts from <a> to <b> triangles with <technique>` and exports the GLB (`export_apply=True`).
- `tools/models/reconstruct.py` (shebang `#!/usr/bin/env -S uv run --python 3.12 --with pymeshlab python -I`, executable): `<in.glb> <out.ply> --technique poisson|alphawrap`. Loads the GLB into a `pymeshlab.MeshSet`, merges the layers (`generate_by_merging_visible_meshes` when more than one), then `generate_surface_reconstruction_screened_poisson(depth=9, samplespernode=1.5, preclean=True)` or `generate_alpha_wrap(alpha=pymeshlab.PercentageValue(1), offset=pymeshlab.PercentageValue(0.1))`, prints `reconstructed <a> to <b> faces with <technique>` and saves the current mesh as PLY.
- `tools/models/decimate.py`: the import picks `bpy.ops.wm.ply_import(filepath=...)` for a `.ply` input and the glTF importer otherwise; the docstring says so.
- `tools/models/close_all.sh` (bash, `set -euo pipefail`, `--dry-run` prints each command instead of running it): for each technique in `fill voxel poisson alphawrap` and each model of the table below, the closed mesh under `work/models/smelter/closed/<model>_<technique>.glb` (or `.ply` for the MeshLab techniques), then `decimate.py` to the model's count into `work/models/smelter/closed/<model>_<technique>_decimated.glb`, then `mesh_blob.py --height 1` into `data/demos/models/meshes/<blob>_<technique>.mesh`. The closed mesh of a base model is made once per technique and decimated to each target. A step whose output exists is skipped, so a rerun continues. The table, as a bash array of `source|count|blob` lines: `model_7_faces24000.glb|20824|faces24000`, `model_7_faces12000.glb|10700|faces12000`, `model_7_faces20000_smart.glb|29476|faces20000_smart`, `model_7_smart.glb|10796|smart`, `model_7_faces12000_smart.glb|10409|faces12000_smart`, `model_7.glb|24000|blender_full_24000`, `model_7.glb|10700|blender_full_10700`, `model_7_faces700000.glb|24000|blender_700000_24000`, `model_7_faces700000.glb|10700|blender_700000_10700`. Blender runs as `flatpak run org.blender.Blender -b --python "$PWD/tools/models/<script>" -- ...` with absolute paths (the flatpak cannot see relative ones outside the home directory).
- `doc/workflows/models.md`: step 1 gains the closing techniques in one sentence each (what the technique does, its tool and parameter), and the tools list the two scripts and the batch.
