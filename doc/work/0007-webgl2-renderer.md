## Specification (main agent, 2026-10-18)

Builds on 0004 (the draw list, the camera, the meshes, the `#+build` rules) and 0006 (the material library). API facts read from `~/opt/odin/vendor/wasm/WebGL` on 2026-10-18: the package is `webgl`, imported as `gl`; `CreateProgramFromStrings(vs_sources, fs_sources: []string) -> (Program, bool)` compiles and links; `GetUniformLocation(program, name: string) -> i32`; `UniformMatrix4fv(location: i32, m: matrix[4, 4]f32)` (the `glm.mat4` alias is that type), `Uniform3f(location, v0, v1, v2: f32)`, `Uniform1f`; `CreateVertexArray() -> VertexArrayObject`, `BindVertexArray`; `CreateBuffer() -> Buffer`, `BindBuffer(target: Enum, buffer)`, `BufferDataSlice(target: Enum, slice, usage: Enum)`; `EnableVertexAttribArray(index: i32)`, `VertexAttribPointer(index: i32, size: int, type: Enum, normalized: bool, stride: int, ptr: uintptr)`; `DrawElements(mode: Enum, count: int, type: Enum, indices: rawptr)`; `Enable`, `DepthFunc`, `FrontFace`, `Viewport(x, y, w, h: i32)`, `ClearColor`, `Clear(bits: u32)` (the bit constants are `Enum`, a distinct u32, so cast them).

- `src/engine/render_webgl.odin` (new, first line `#+build js wasm32`, `package engine`, imports `gl "vendor:wasm/WebGL"` and `"core:math/linalg"`). `Webgl_Mesh :: struct { vertex_array: gl.VertexArrayObject, vertex_buffer, index_buffer: gl.Buffer, index_count: int }`. `Webgl_Uniforms :: struct { model, view, projection, sun_direction, sun_colour, ambient, albedo: i32 }`. `Webgl_Renderer :: struct { program: gl.Program, uniforms: Webgl_Uniforms, meshes: [dynamic]Webgl_Mesh }`. `WEBGL_AMBIENT :: 0.15` with a comment that the sky ambient of stage 1 replaces it. `webgl_renderer_init :: proc(renderer: ^Webgl_Renderer) -> bool`: the program from the two sources below, false when it fails, the uniform locations by name, then `Enable(DEPTH_TEST)`, `Enable(CULL_FACE)`, `FrontFace(CCW)`, `DepthFunc(LEQUAL)`. `webgl_renderer_upload_mesh :: proc(renderer: ^Webgl_Renderer, mesh: Mesh_Data) -> Mesh_Id`: a vertex array, the vertex buffer filled with `BufferDataSlice(ARRAY_BUFFER, mesh.vertices, STATIC_DRAW)`, attribute 0 the position (3 floats, stride `size_of(Vertex)`, offset 0) and attribute 1 the normal (offset `offset_of(Vertex, normal)`), the index buffer filled from `mesh.indices` as `ELEMENT_ARRAY_BUFFER`, the vertex array unbound, the mesh appended, its index as the id. `webgl_renderer_draw :: proc(renderer: ^Webgl_Renderer, list: Draw_List, library: Material_Library, width, height: i32)`: viewport, clear colour `{0.05, 0.06, 0.08, 1}`, clear colour and depth, use the program, aspect `f32(width) / f32(max(height, 1))`, the view and projection uniforms from 0004's procedures, the sun direction normalised and the sun colour times its intensity, the ambient constant; then per item: skip it when its material or mesh id is out of range, else the albedo, the model matrix, bind the mesh's vertex array and `DrawElements(TRIANGLES, index_count, UNSIGNED_INT, nil)`.
- The shaders, two string constants in the same file, GLSL ES 3.00. Vertex: `layout(location = 0) in vec3 position; layout(location = 1) in vec3 normal;` uniforms `model`, `view`, `projection`; `out vec3 world_normal = mat3(model) * normal` (uniform scale assumed, said in the doc); `gl_Position = projection * view * model * vec4(position, 1.0)`. Fragment: `precision mediump float;` uniforms `sun_direction`, `sun_colour`, `ambient`, `albedo`; `diffuse = max(dot(normalize(world_normal), -sun_direction), 0.0)`; `linear = albedo * (ambient + diffuse * sun_colour)`; output `vec4(pow(linear, vec3(1.0 / 2.2)), 1.0)`. The sun direction is the direction the light travels, towards the scene.
