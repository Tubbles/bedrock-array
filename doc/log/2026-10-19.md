The reviewer's scripted pad drove the real loop through nine menu round trips and read the resident size per trip: about 65 MB more each time, since `scene_view_destroy` frees no GL object and the renderer has no destroy. It did no harm while the view lived until exit. The fix is engine work and becomes item 0078, landed next, before the play build. Two couch details the specification missed: raylib's `EnableCursor` warps the pointer to the window's centre, over a row the pad drives, so the pointer stays hidden on the menu in borderless mode, and the demo descriptions end in the pages' mouse and keyboard hints, so a row shows the first sentence. Cadence: implementer 155 s of agent time, reviewer 347 s (two probes), the main agent's fixes and landing about twelve minutes.
