# Bedrock Array

A factory game on smooth voxel planets, heavily inspired by Techtonica, played from the couch with a gamepad. The game itself is a set of WebAssembly modules on its own voxel engine, so a mod can reach as deep as the game does, in the spirit of the Warcraft 3 world editor.

Odin and raylib, modules in Odin compiled to wasm and run on wasmtime.

Status: pre-alpha, the tech demo phase. The intent is in [definition.md](definition.md), the decisions in [DESIGN.md](DESIGN.md), the way there in [PLAN.md](PLAN.md), the details under [doc/](doc/README.md).
